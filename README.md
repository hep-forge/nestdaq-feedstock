Feedstock for [nestdaq-current](https://github.com/spadi-alliance/nestdaq) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

Streaming data acquisition framework based on FairMQ and Redis

## Architectures

State per architecture: see the platforms badge above or [anaconda.org/hep-forge/nestdaq-current](https://anaconda.org/hep-forge/nestdaq-current).


## Install

```bash
conda install -c hep-forge -c conda-forge nestdaq-current
```
